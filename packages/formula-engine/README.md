# @nodus/formula-engine

Движок формул в ячейках атрибутов (#632, ADR-0037 п.3, ADR-0029 «Дополнение 06.11»).
Чистый TypeScript без зависимостей, кроме `@nodus/contracts`: одна реализация
вычисления для API, MSW-моков и редактора (parity моков по построению).

## Состав

| Файл            | Что                                                                                                     |
| --------------- | ------------------------------------------------------------------------------------------------------- |
| `evaluate.ts`   | `evaluate(ast, resolver)` — чистое вычисление; ошибка ячейки результатом, не исключением                |
| `infer-type.ts` | `inferType(ast, meta)`, `validateFormula(ast, opts)` — статический тайпинг и проверка перед сохранением |
| `deps.ts`       | `extractDeps(ast)` — дескрипторы зависимостей для `formula_deps`                                        |
| `types.ts`      | `FormulaResolver` (единственная точка чтения данных), значения, результаты                              |

## Правила языка

- Адресация атрибутов — внутренний `number` (переименование не ломает формулу).
- Источники одного значения: `self`, `parent_task`, `folder_nearest`, `project`,
  `company`, `ref_field`. Многозначные (`related`, `folder_chain`) — только
  внутри агрегата; матрица допустимости — в contracts (`FORMULA_SOURCE_MATRIX`).
- Null-семантика: пустой источник → null; арифметика с null → null; `&`
  пропускает null; сравнение с null → false; агрегаты игнорируют null
  (кроме СКОЛЬКО).
- Деньги считаются в минорных единицах (целые, без float-погрешности);
  разные валюты → `type_mismatch`.
- `enum`/`multienum` в формулах — **подписи вариантов** (резолвер владельца
  разворачивает id → имя); при записи в список сервер сопоставляет подписи
  с id словаря. Ссылки на записи остаются id (`ref`).
- Циклы ловит оркестратор пересчёта глубиной волны (`FORMULA_LIMITS.cascadeDepth`),
  не движок; движок отдаёт `cycle` только если его передали снаружи.

## Резолвер

Резолвер реализуют порты владельцев данных (ADR-0012): он обязан вернуть
`null` для недоступного источника и отфильтровать выборку агрегата (чужой
проект, конфиденциальные и мягко удалённые записи, Р7). Движок не умеет
читать мимо резолвера — это структурная гарантия безопасности формул.

## Проверки

- `validateFormula` возвращает блокирующие проблемы (422: AST, тип, источник,
  лимит) и неблокирующие (`attribute_deleted` — ячейка покажет ошибку,
  сохранение не отклоняется).
- Лимиты: глубина 12, узлов 60, источников 8, литерал 500, выборка 500,
  глубина волны 8 (`CUSTOM_FIELD_LIMITS` / `FORMULA_LIMITS`).
