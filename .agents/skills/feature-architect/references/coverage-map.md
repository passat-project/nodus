# Карта покрытия: поверхность фичи → обязательные разделы плана → линзы

Ф0 выписывает поверхности; дальше работа идёт ПО СТРОКАМ этой таблицы: каждая
затронутая поверхность требует свои разделы/артефакты плана и свои линзы закалки.
Пропущенная строка = дыра плана; строка «не применимо» — только с причиной.

| Поверхность (из Ф0) | Обязательные разделы/артефакты плана | Линзы |
|---|---|---|
| Новая сущность/поля | §3 (проверено по коду); миграция expand/contract; трассы §4a; ВСЕ производители вычисляемого поля; сид через контрактные схемы | 1, 2 |
| Права/секретность | матрица инвариантов (§6); гейты точек входа (§4) со строкой «что НЕ применяется»; API-таблица; данные доказательств от ≥2 пользователей | 3, 8 |
| Экраны/потоки | §4c композиция КАЖДОГО экрана (анатомия — вердикт владельца до кода); §7 UI-пакеты и план Б; умолчания переиспользуемых запросов | 5, 7 |
| События/контракты | §6 потребители событий (+аудитория и момент расчёта; мутация границы модели — строка эмитов); freeze §8 с зеркалами; grep потребителей новых членов перечислений | 4, 9 |
| Чужие системы/зависимости | §3 конвенции; формы значений (таблица «значение → форма → нормализация»); вес зависимости в тулчейне; проба до плана или fallback | 10, 11 |
| Порядок/фоновая работа | инвентарь механизмов Ф3 + карта ресурсов (таблица/JSONB → все писатели → ключ/лок → тест гонки); тройка «механизм + владение + проверка срыва»; бут-гейт фазы | 1, 11 |
| Кэш/производительность | таблица свежести (must-be-fresh / stale-tolerant); последняя миля трассы (событие → ключ кэша → экран) | 11 |
| Миграции/выкатка | §10 риски, выкатка и откат; сид и бутстрап песочницы; перепись данных — порождающий replay-набор (фикстуры из механизма миграции) + инварианты постпроверки, гейт фазы; базовый замер drift до первого изменения | 4, 10 |
| Фичефлаг | поведение при выключенном (I10): порты нейтральны, HTTP-модуль гаснет; сочетания флагов на пути | 4, 10 |
| Мок-мир (MSW) | §6 мок-инварианты списком (ошибки, required/unknown, архивность, права) + parity-тест на каждое | 4 |

Гейт: для каждой поверхности Ф0 пройдена своя строка; артефакты строки есть в плане
или «не применимо: причина»; линзы строки включены в закалку Ф4.
