# Аудит кода

Одна папка на аудит: `docs/audit/<ГГГГ-ММ-ДД>/`.

Правила:

- В репозиторий кладётся **курированный** набор: вердикт по находкам, карточки задач, план, вопросы владельцу, индекс (`README.md` в папке).
- **Сырые отчёты субагентов в git не попадают** — они эвристические, объёмные и читаются как факты. Их место — временная папка вне git до разбора темами; после разбора удаляются.
- Каждая папка начинается с фразы «снимок на дату, а не канон»: при расхождении с кодом верен код.
- Находки аудита не замалчиваются: реальные дефекты уходят в issues, а не остаются только в отчёте.
