# #737 follow-up — анимация движения карточек при переносе

Снято Playwright'ом с песочницы live-stack (`http://127.0.0.1:4173`, vite dev,
non-mock, БД `nodus_night`, `night-a@nodus.local`), окно 1280×800. Видео —
улика механики (FLIP), не приёмка: ощущение движения оценивает владелец.

- `01-kanban-dnd-motion.webm` — перенос первой карточки «Новые» в «На
  утверждении»: вход в колонку, «между 2-й и 3-й», «в самый верх», «в самый
  низ», затем Escape (данные не менялись). Видно, как карточки едут за слотом,
  а не прыгают.

Числовая проверка того же сценария (проба `.live-stack/probe-dnd-motion.mjs`,
в репо не входит): `Element.animate` получает FLIP-сдвиги
`translate(0, 105–254px)`, к 320 мс все трансформы нулевые; слоты
«между/верх/низ» и drop остались прежними (FLIP не участвует в выборе места —
инверсия стороны невозможна).
