# Кадры #1054 — управление видео под кадром, вплотную

Песочница live-stack (`http://127.0.0.1:4173`, preview, **non-mock**, БД `nodus_night`),
окно 1600×950 и 900×800, обе темы. Ролик — `probe-video (1).webm` из беседы
«Проверка #250 — видео в чате» (`night-a@nodus.local`), съёмка Playwright'ом.

Итог по указаниям владельца: тёмный фон зала остаётся (#790); браузерная полоса,
которая притемняла низ кадра, убрана; своя полоса — **вплотную под кадром, без зазора,
ровно по его ширине**, кружки ползунков — ровно на линии и в позиции значения
(«ползунок остаётся там, где был… ровно под видео без отступов», «ползунки съехали — отцентруй»).

Геометрия подтверждена пробой (обе темы, узкое окно): полоса и кадр — `flush`, `sameWidth`,
`sameX` (расхождение ≤ 1px), поверх кадра наложений нет. Кружки ползунков — ровно на линии
дорожки (пиксельный замер: центры совпадают, ≤ 1px) и ровно в позиции значения
(клик по 60% → 6.4 с из 9.92, перетаскивание на 20% → 2.4 с; живой стенд `:4173`).

Скрипты проб — `.live-stack/probe-1054-shots.mjs` (до/после),
`.live-stack/probe-1054-final.mjs` (финальные кадры) и `.live-stack/probe-1054-pixels.mjs`
(пиксельный разбор ползунков); эталонные кадры прогона `ui-writer` —
`.live-stack/shots/ui-writer-1054/` (все пути в git не входят).
