# Кадры #1054 — управление видео под кадром, вплотную

Песочница/контур владельца (`http://localhost:5173`, фронт ветки + живой API ночного
стенда), окно 1600×950 и 900×800, обе темы. Ролик — `probe-video (1).webm` из беседы
«Проверка #250 — видео в чате» (`night-a@nodus.local`), съёмка Playwright'ом.

Итог по указаниям владельца: тёмный фон зала остаётся (#790); браузерная полоса,
которая притемняла низ кадра, убрана; своя полоса — **вплотную под кадром, без зазора
и ровно по его ширине** («ползунок остаётся там, где был… ровно под видео без отступов»).

`sameX` (расхождение ≤ 1px), поверх кадра наложений нет.
