# Кадры #737 — слот вставки карточки канбана с любой стороны

Снято Playwright'ом с песочницы live-stack (`http://127.0.0.1:4173`, vite dev,
**non-mock**, БД `nodus_night`, пользователь `night-a@nodus.local`), обе темы,
окно 1600×950. Кадры — улика исполнения, не приёмка: вкусовое суждение — за
владельцем.

## Сценарий

Первая карточка колонки «Новые» удержана и проведена в колонку «В работе»
(12 карточек):

- `01-kanban-dnd-between__{light,dark}.png` — указатель в зазоре между 2-й и
  3-й карточками: борд переставил карточку живьём ещё до отпускания, слот стоит
  между ними; drop встал бы ровно туда.
- `02-kanban-dnd-top__{light,dark}.png` — указатель над 1-й карточкой: слот в
  самом верху колонки — сценарий, который до фикса был визуально недостижим.

Кадры сняты до отпускания, затем Escape — данные не менялись.

## Почему нет пары «до»

Дефект — поведение DnD (слот вставал на противоположной стороне), а не
статичный вид: «до» на кадре — это потерянная сторона вставки, её фиксирует
живое репро владельца и механизм в `docs/gotchas/frontend.md`. Снимать «до»
пришлось бы откатом стратегии в общей песочнице приёмки (`:4173`) — это
трогало бы контур владельца; фикс-ветка и есть единственная проверяемая
сборка.
