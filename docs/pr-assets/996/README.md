# #996 — уведомление о смене срока задачи

Кадры живого контура: песочница `:4173` (preview, non-mock, БД `nodus_night`),
окно 1440×900, обе темы. Демо-данные созданы настоящим конвейером портала:
постановщик `night-a@nodus.local` перенёс и снял срок задачи
«Проба 996 смена срока …», ответственный `night-b@nodus.local` видит строку
в ленте «Главной».

| Файл | Что показывает |
| --- | --- |
| `deadline-notification-light.png` | Главная, светлая тема: строка «Срок изменён · ПП-108 · …» в «Требуют внимания», +2 события (перенос и снятие срока) |
| `deadline-notification-dark.png` | То же в тёмной теме |

Полный текст превью (проверен живой пробой через API): «ПП-108 · Проба 996
смена срока … · до 15 января, 17:00» и «… · срок снят»; в строке ленты длинное
название пробы обрезается по ширине карточки.
