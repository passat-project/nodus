# ADR-0044. Облачный LLM-провайдер для ИИ-ассистента — временное исключение I11

- **Статус:** Принят
- **Дата:** 2026-11-17
- **Контекст:** I11 (self-hosted, zero cloud в рантайме) и north-star §7 («приоритет self-hosted, пилот на облачном API — исключение через ADR»). ADR-0032 уже разрешил облачные эмбеддинги/реранк/LLM для смыслового поиска. Эпик #889: ассистент нужен сейчас, локальное железо (~48 ГБ видеопамяти) дорого; владелец использует подписку OpenCode Go; позже возможен локальный Qwen на своём ПК.

## Контекст

Ассистент без модели не работает. Локальный контур на первом этапе недоступен по железу; владелец сознательно допускает облако для служебной переписки (тестовая группа, реальных данных пока нет) и планирует переключение на локальный провайдер при необходимости. Провайдер должен меняться настройкой, без переписывания кода и без перезапуска.

## Решение

1. **Облачный LLM — временное, отключаемое исключение из I11** для модуля `assistant`, расширяющее ADR-0032. Исключение действует, пока включён флаг `assistant`; выключение флага или провайдера возвращает портал в self-hosted-режим без ассистента.
2. **Провайдер настраивается администратором** в «Настройках портала → ИИ-агент»: список OpenAI-совместимых провайдеров (OpenCode Go, OpenRouter, OpenAI, локальные Ollama/vLLM), ключи, модели, дефолт. Локальный провайдер — тот же порт `LlmProvider`, без изменения кода.
3. **Модели с обучением на данных запрещены.** Используются платные модели с нулевым хранением и запретом обучения; бесплатные модели с оговоркой «данные используются для улучшения» (Beam Free, Iceman Free, Muse Contributor, Nemotron Free и т.п.) в портале не подключаются. Для OpenCode Go DeepSeek V4.1 Flash официально: 0 дней хранения, не для обучения.
4. **Ключи — только в шифрованном виде** (`core/crypto`), наружу не возвращаются, в логи и аудит не попадают. Доступ к настройкам — право `portal.settings.manage`.
5. **Границы данных:** вложения не читаются вообще (ни конфиденциальные, ни обычные) — только метаданные; тела писем и чаты — в пределах прав сотрудника; чаты — корпоративная переписка компании.
6. **Локальный провайдер — штатный путь**, а не аварийный: при появлении GPU или требовании заказчика админ добавляет `http://localhost:.../v1`, выбирает модель и отключает облачного провайдера. Код не меняется.
7. **Аудит и наблюдаемость:** настройки провайдеров — аудит; прогоны — токены, модель, длительность; ошибки провайдера — понятные, без утечки тела ответа.
8. **Никаких квот запросов** (решение владельца): только технические предохранители (шаги, таймаут, размер результата).

## Альтернативы

| Альтернатива | Почему отклонена | Когда пересмотреть |
| --- | --- | --- |
| Только локальная модель с первого дня | ~48 ГБ видеопамяти, дорого и долго; владелец хочет проверить ценность сейчас | Появится GPU-сервер или требование заказчика |
| Без ИИ до появления локального контура | Теряется время проверки главной фичи; данные тестовые | — |
| Жёстко зашитый провайдер в `.env` | Смена провайдера требует перезапуска и правки сервера; неудобно админу | Никогда — противоречит решению |
| Разрешить бесплатные модели «для теста» | Обучаются на данных, смешиваются с прод-потоком | Отдельный контур с явной пометкой и согласием |

## Последствия

**Проще:** ассистент запускается сейчас; смена провайдера — настройка; локальный контур — тот же код; ключи не в репозитории.

**Сложнее:** контроль выбора моделей (админ должен понимать политику хранения); зависимость от внешнего сервиса в рантайме (деградация — понятная ошибка, не падение портала); ротация ключей.

**Риски и меры:** утечка ключа — шифрование, маска, запрет логов; обучение на данных — белый список моделей, бесплатные запрещены; недоступность провайдера — ошибка с кодом и повтором, портал работает; приватность — вложения не читаются, доступ по правам, аудит.

## Обоснование (research)

- OpenCode Go privacy table: DeepSeek V4.1 Flash — «Not used» (обучение), «0 days» (хранение); ZDR-соглашение продлевается ежемесячно.
- OpenCode privacy policy: промпты передаются провайдеру и не хранятся (кроме hosted agents); upstream — zero-retention.
- OpenRouter: OpenAI-совместимый API, `/models`, tool calling; политика хранения зависит от модели-апстрима — выбор модели остаётся за админом.
- ADR-0032: облачный контур смыслового поиска уже принят как временное исключение; ассистент использует тот же принцип.
