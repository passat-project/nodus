# ADR-0040. Фон зоны чата: исключение из канона плоскости

- **Статус:** Принят
- **Дата:** 2026-11-13
- **Контекст:** issue #849, вердикт владельца 13.11.2026: «мне нравится, можешь мержить». Канон UI (`nodus-ui-style`, правило 3) требует плоскость без текстур и градиентов; владелец принял декоративный фон зоны чата как исключение.

## Контекст

Скриншоты Nodus, вставленные в белый документ или презентацию, не имеют видимой границы: лента чата — ровная светлая плоскость, и по ней невозможно понять, где заканчивается приложение. Владелец предложил модель Telegram/Битрикс24: мягкая цветная подложка + плотная хаотичная россыпь отдельных иконок. Канон «Инструмент» прямо запрещает текстуры, градиенты и декор внутри панелей, поэтому нужно явно зафиксированное исключение — иначе следующий агент удалит фон как баг.

## Решение

### 1. Где можно

Класс `.chat-wallpaper` допускается **только на корнях лент чата**:

- `conversation-pane` — беседа/личный чат/чат задачи и письма;
- `thread-pane` — окно треда;
- `thread-feed` — лента канала;
- `notes-pane` — «Заметки»;
- `notes-source-window` — лента исходной беседы в окне заметок;
- пустое/ошибочное состояние обсуждения задачи (`task-discussion`).

Вне исключения: список бесед, правая панель, шапки, композер-остров, настройки, карточки сотрудников и любые другие поверхности. Новый хост фона — только через правку этого ADR.

### 2. Из чего состоит слой

- База — токен `--chat-zone` (ступень углубления ленты).
- Светлая тема: тёплая бумага `--chat-wallpaper-paper-*` + слабое индиго-свечение `--chat-wallpaper-wash`; сила иконок 8%.
- Тёмная тема: `--chat-wallpaper-base-*` (чёрная основа) + закатные радиальные пятна `--chat-wallpaper-violet/rose/orange` + нижний scrim `--chat-wallpaper-scrim`; сила иконок 6%.
- Плитка — статичный SVG-ассет `packages/ui/src/assets/chat-wallpaper-{light,dark}.svg`, 960 px, `background-repeat: repeat`, бесшовная (элементы на краю дублируются). Цвет и сила запечены в SVG: `background-image` не поддерживает `currentColor` — задокументированное исключение статичного файла.
- Слой статичен, без анимации: `background-image` на элементе не скроллится с содержимым ленты (модель обоев Telegram).
- Полоса композера прозрачная; сам остров ввода остаётся `bg-card` и лежит поверх фона.

### 3. Состав плитки и лицензии

120 уникальных форм: 113 Lucide 1.66 (ISC), башенный кран — Tabler Icons (MIT), 5 собственных (экскаватор, конвейер, труба, жилет, уровень), знак Nodus с окна входа. Тексты лицензий — `docs/design/messenger-wallpaper/LICENSES.md`. Генератор — `docs/design/messenger-wallpaper/gen-wallpaper.cjs`; раскладка blue-noise, самопроверка зазоров входит в генерацию.

### 4. Правила для будущих правок

- Менять палитру — только через токены `--chat-wallpaper-*` в `:root` / `[data-theme='dark']`.
- Не переносить фон на список бесед, панели и шапки: граница «где чат» — часть решения.
- Не анимировать слой и не вставлять в него семантические элементы (фон декоративный, `aria-hidden` не требуется — это `background-image`).

## Альтернативы

| Альтернатива | Почему отклонена | Когда пересмотреть |
|---|---|---|
| Готовые обои-пресеты как в Битрикс24 | Нет привязки к бренду; владелец хочет акцент Nodus (данные/графы/ИИ/автоматизация) | Если появятся пользовательские обои |
| Растровые фотографии/паттерны | Два файла под темы, вес, размытие при масштабе, хуже чёткость | Если понадобится зерно/бумага |
| Только CSS-градиент без плитки | Не даёт границы на однотонном фоне при кропе | — |
| Фон на всю поверхность мессенджера | Список бесед становится шумнее, текст хуже читается | — |
| Маска `mask-image` + один SVG | Требует отдельного слоя под скроллером; два запечённых SVG проще и предсказуемее | При росте числа тем |

## Последствия

- Скриншоты получают физическую границу; экран чата визуально отличается от остальных панелей.
- В тёмной теме появляется цветной градиент — риск бандинга; проверено на 100% и 125%, при проявлении добавляется слабое зерно отдельным решением.
- Ассеты +~62 КБ на тему; статичный `background-image` не перерисовывается при скролле.
- Исключение узкое: любой выход за перечень поверхностей — новый ADR или откат к плоскости.

## Обоснование (research)

- Telegram: заливка (solid / gradient / freeform) + монохромный паттерн с `intensity`, `rotation` кратен 45° — <https://core.telegram.org/api/wallpapers>; разобранный набор Android 5.14.0 (39 фото, 7 PNG, 33 SVG) — <https://blog.1a23.com/2020/02/13/telegram-chat-backgrounds-patterns-extracted/>.
- Читаемость на текстурах: важна пространственная частота, а не сама текстура — <https://doi.org/10.1364/oe.6.000081>, <https://doi.org/10.1080/00140139.2020.1758348>.
- Pattern glare / муар мелкой плитки — <https://www.frontiersin.org/journals/psychology/articles/10.3389/fpsyg.2015.01651/full>.
- Практика фонов в интерфейсах: статичный слой, низкий контраст, без анимации — <https://ux.stackexchange.com/questions/92986/background-patterns-do-or-dont>.
