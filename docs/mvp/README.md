# docs/mvp — рабочая зона треков: карта

Единого плана трека в этой зоне больше нет (решение 15.11.2026). Картина продукта — `docs/product/unified-model.md`; стратегия и бизнес-кейсы — `docs/product/roadmap.md`; состояние и порядок — issues и чеклисты эпиков. Этот файл — карта зоны и её правила.

## Что где

| Что | Роль |
|---|---|
| `process-map.md` | Карта ядра управления проектированием (процесс А: письмо → поручение) |
| `process-model-plan-2026-10-25.md` | Указатель: план от 25.10 перенесён в `archive/`; в файле — что из него в силе и что заменено |
| `plans/` | Локальные черновики планов задач; в git не попадают (`.git/info/exclude`), исполнитель чистит при закрытии issue |
| `archive/` | Отработанные планы и промпты сессий — история «как решили», не канон; индекс — `archive/README.md` |

## Агенту: как понять «что делать дальше»

1. `docs/product/unified-model.md` — как устроен продукт целиком и в каком порядке собирается (§9).
2. `docs/product/roadmap.md` — какой бизнес-кейс и фаза, что отложено.
3. Чеклисты эпиков #377 (ядро автоматизации), #49 (проекты), #50 (корреспонденция) — порядок и зависимости issues.
4. Текущее состояние — issues (`gh issue list`); детальный план задачи — комментарием в issue при взятии, не отдельным файлом.

## Правила зоны

- Новых «планов трека» и «промптов сессий» в корне не создаём. Выводы сессий и находки — в единую модель, ADR, инкубатор или комментарий issue.
- Документ отработал (решения в каноне, трек закрыт) → тем же коммитом в `archive/` + строка в `archive/README.md`.
- Зона временная: после MVP (20.12.2026) сворачивается целиком — канон живёт в `docs/` и ADR.
