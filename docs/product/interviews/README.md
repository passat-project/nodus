# Интервью и обсуждения с руководством — локальные материалы владельца

Саммари и полные транскрипты интервью **в репозитории не хранятся** (решение владельца 12.11.2026): это личные материалы собеседников — имена, должности, откровенные высказывания о процессах и людях. Репозиторий публичный, поэтому папка живёт только на ПК владельца, а здесь остаётся один этот файл-указатель.

## Что это значит на практике

- **В свежем клоне папки нет** — и это нормально. Агент работает по канону без неё: `docs/product/north-star.md`, `docs/product/core-flows.md`, roadmap, ADR, issues.
- **На ПК владельца** папка существует целиком: саммари (`ГГГГ-ММ-ДД-<кто-или-тема>.md`), полные очишенные транскрипты в `full/` (имя файла = имя саммари) и локальный указатель `_local-index.md` (кто, роль, длительность, на что повлияло).
- **Если папка есть локально** — перед планированием, нарезкой issues и работой по корреспонденции/проектам/ИИ читаются саммари; `full/` открывается точечно, когда нужна дословная формулировка или таймкод.
- **Новое интервью** оформляется там же, локально: саммари по правилам ниже + полный транскрипт рядом. В git не добавляется — `.gitignore` закрывает всё, кроме этого файла.
- **Ссылки из документов** на интервью (ADR, планы, инкубатор) указывают на папку, а не на конкретный файл: у остальных она не откроется — так и задумано.

## Формат саммари (локально)

- Один разговор = один файл, имя `ГГГГ-ММ-ДД-<кто-или-тема>.md` (ASCII, kebab-case).
- Шапка: дата, участники, длительность, источник и способ расшифровки, ссылка на полный транскрипт в `full/`.
- Тело по темам: суть → «значит для Nodus» (терминами канона, со ссылками). В конце — «Подтверждения канона», «Открытые вопросы» и таблица «тема → куда в плане» (`→ #N`, когда тема стала issue).
- Цитаты — короткие, близко к расшифровке. Файлы не удаляются.

## Формат полного транскрипта (`full/`, локально)

- Очищенный полный текст: слова-паразиты и повторы убраны, **содержание сохранено полностью** — это не саммари.
- Реплики владельца — с тире «—», ответы собеседника — без пометки; имена говорящих в теле не проставляются.
- Таймкоды `[ЧЧ:ММ:СС]` — для интервью от 22.10.2026; более ранние без них, порядок реплик сохранён.
- Пометки: `[нрзб]`/`[неразборчиво]` — не восстановлено по аудио, `[?]` — неоднозначное место, `*` — исправленное искажение ASR.
- Аудио-оригиналы и сырые проходы ASR — вне репозитория и вне папки.
