# И-019 · Вопрос-ответ по BIM-модели

**Дата:** 2026-10-01

**Суть:** ассистент отвечает по BIM-модели и строительным нормам (NormaCore): «почему здесь такая стена», «какой объём бетона», «что говорит норматив». Владелец: продукт строится вокруг ИИ-ассистента, а важнейший класс знаний — строительные источники.

**Разбор:** сложность не в LLM, а в трёх слоях. (1) IFC — формат обмена, не база для вопросов: свойства размазаны, геометрия тяжёлая; нужен канонический JSON из плагина Revit, IFC — вторичным адаптером. (2) Нормы — отдельный индекс; у NormaCore нужен API и ключ идентификации элемента (IFC GUID?). (3) Метафора «агент исследует модель как кодовую базу»: инструменты навигации по модели, а не один огромный контекст — иначе токены и галлюцинации.

**Открытые вопросы:** есть ли API у NormaCore и по какому ключу он идентифицирует элементы? Кто владелец плагина Revit? Регламент обновления индекса при новой версии модели? Что в первой версии — объёмы, свойства, нормы?

**Связи:** И-017 (ИИ-агент), #272 / M18 (индекс и поиск), roadmap V3 / «Платформа».

**Статус:** обсуждается.
