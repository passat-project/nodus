# И-033 · Зёрна из вердиктов #52

**Дата:** 2026-10-29

**Суть:** четыре идеи из волн вердиктов владельца 29.10 по ядру проектов, осознанно вне ядра:

1. **Чат проекта «канал + чат + автолинк»** — у проекта не только канал (важные новости), но и чат «как в телеграмме»; публикация в канал автоматически бросает ссылку в чат.
2. **«Присоединиться к задаче» из проекта** — не-участник видит чужие задачи проекта и может стать наблюдателем задачи или написать в её чат и стать наблюдателем автоматически.
3. **Вкладка «Активность» проекта** — лента событий проекта из event log (I9): переходы задач, смена состава, правки полей.
4. **Портфель как носитель общих настроек** — состав проектов наследует настройки портфеля.

**Разбор:** (1) дублирует пространство проекта из ADR-0030 п.9 — делать вместе с ним одним решением; (2) вторая дверь к задаче, риск путаницы «наблюдатель задачи ≠ участник проекта» уже снят вердиктом В3, дёшево после чатов задач; (3) тривиально поверх event log, ценность — наблюдение руководства; (4) не нужно, пока у портфеля нет ни одного собственного поля.

**Открытые вопросы:** чат проекта — в декабре или после? «Активность» — кому видна: всем участникам или руководству?

**Связи:** ADR-0030 п.9, #456 (пространство и чат проекта), #52, #433.
