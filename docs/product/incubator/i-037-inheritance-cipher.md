# И-037 · Атрибуты на весь портал, формулы и наследование

**Дата:** 2026-11-03

**Суть:** владелец: один атрибут служит разным сущностям (задачи, письма, папки, проекты, реестры) — привязка галочками вместо вкладок-областей; наследование от родителей — must-have и живое (задачу переносят между папками и проектами, меняют родителя); шифр комплекта собирается из кодов проекта и папок любого уровня; нужны значения на всю компанию.

**Разбор:** согласовано 03.11 — атрибут один на портал: номер выдаёт система, название уникально, в формулах — плашки (переименование обновляет всё). «Где используется» — галочки по модулям до типов и видов, та же привязка из формы типа/вида; «Атрибуты» — одна таблица с фильтром по модулю; обязательность, порядок, умолчание — у формы. Удаление — всегда, с перечнем того, что сотрётся. Ячейка — значение или «=формула», как в Excel: плашки своих полей, родителей (проект, папка по виду, цепочка папок, родительская задача), ссылок, компании, поиск по реестрам (аналог ВПР); формула живая, её вписывает тот, кто правит поле; тип/вид задаёт формулу по умолчанию, запись можно переписать значением руками. Наследование — доступ из формул, без копий. Шифр и название тоже принимают формулу; в окнах — подстановки, сохраняются значением. «Компания» — значения на всю компанию. Формулы видят только своё дерево проекта и общие данные.

**Открытые вопросы:** набор функций формул; менять ли значения компании кнопками (переменные); совпадение вычисленных шифров в проекте.

**Связи:** И-039; #556, #557, #38, #468, #469, #431, #432, #436; ADR-0029, ADR-0030.

**Статус:** обсуждается — ждём одобрения общей модели вместе с И-039.
