# И-041 · Вкладки карточек: сплит/каскад как в VS Code

**Дата:** 2026-11-04
**Статус:** обсуждается
**Суть:** владелец: «сделать работу с вкладками более продуманной, чтобы их можно было каскадом растаскивать и одновременно работать в чате и в файле вложения; DnD вкладки в область центральной основной панели или команда ПКМ по вкладке — как в VS Code».

**Разбор:**

- **За:** главный сценарий — читать вложение и обсуждать его в чате без переключения вкладок; сравнение двух файлов; меньше потерь контекста.
- **Против/риски:** карточка узкая — два пейна съедают ширину; ONLYOFFICE-iframe тяжёлый (два редактора — память/CPU); текущая модель вкладок плоская (`files/active/visited`) — нужна модель групп, активной вкладки на группу, DnD-состояния и тесты; конфликт с левой панелью данных, если тащить вкладку в «центр».
- **Варианты:** (1) контекстное меню «Открыть рядом» / «Разделить вправо» — минимальный вход; (2) кнопка split в полосе, активная вкладка открывается вторым пейном; (3) полноценные группы вкладок с DnD-каскадом (VS Code) — максимум гибкости, больше кода и рисков; (4) одна зона + «закрепить вложение» поверх чата.
- **Рекомендация:** начать с (1)+(2) — два пейна в правой зоне (чат + файл), ресайз с памятью, контекстное меню; DnD-каскад — после проверки сценария.

**Связи:** #603 (общая полоса вкладок), #542 (письмо), карточки задачи/письма/проекта, `shared/ui/entity-card/card-tab-strip.tsx`, VS Code editor groups.

**Открытые вопросы:**

1. Второй пейн — только правая зона (чат | файл) или можно тащить в левую панель данных?
2. Максимум пейнов — 2 или 3? Что делать на узкой карточке — стек/вкладки?
3. Сохранять раскладку при закрытии/повторном открытии карточки? Глобально или на сущность?
4. Нужны ли две вкладки файлов рядом без чата (сравнение документов)?
5. Делать только в задаче или сразу во всех карточках (письмо/проект)?
