# И-017 · ИИ-агент в центре портала

**Дата:** 2026-09-30

**Суть:** Битрикс проиграл не отсутствием функций, а их количеством — люди пользовались малым. Агент-чат в центре портала превращает разговор в структурированные данные: создать проект или задачу, найти письмо, ответить по данным. Техническая опора уже есть: I2 («действие UI воспроизводимо скриптом») — это готовая точка входа.

**Разбор:** вердикты владельца 30.09 — первый пилот на облачном API (локальный ИИ дорог по железу); первый кейс — создание проектов; ответственность несут сотрудники, в логах — пометка «через ИИ»; реализация строго после базы (после 20.12).

**Крючки сейчас (цена — ноль кода):** канон атрибуции «исполнитель + via-ИИ» в data-model/api-conventions; признак конфиденциальности у сущностей, попадающих в контекст; агент-линза при ревью декабрьских модулей; #19 (OpenAPI из кода) как будущий каталог инструментов.

**Не делаем сейчас (I13):** LlmProvider, VectorStore/pgvector, MCP-сервер без потребителя.

**Дизайн каталога инструментов (канон для ADR в момент реализации):** один каталог — три потребителя (ассистент, MCP, UI-подсказки); «три полки» — ≤ 15 always-on инструментов, полный каталог за мета-тулом `search_tools` с векторным индексом описаний, навыки-сценарии для многошаговых регламентов; имена с префиксом модуля, описания из OpenAPI-аннотаций — единственный источник истины. Подробности — в git-истории записи 30.09.

**Открытые вопросы:** приватность — допустимо ли облако для текстов писем и задач? Первый поток после проектов? Бюджет токенов и лимиты?

**Связи:** north-star §2–3, #19, И-008, И-019; MCP-дизайн — git-история записи 30.09.

**Статус:** зреет — триггер: запуск базы (после 20.12) и готовый #19.
