# И-009 · Миграция на TypeScript 7

**Дата:** 2026-09-23

**Суть:** Dependabot тянет TS ~7.0.2 (нативный компилятор) — отложено до «после запуска», мажоры игнорируются в `dependabot.yml` (#75).

**Разбор:** это не новый язык, а новый движок компилятора (Go). Сейчас 5.9.3; typescript-eslint не поддерживал новый компилятор (peer `< 6.1`) — отсюда отсрочка. Выигрыш — кратный рост скорости компиляции; наш typecheck пока ~минута, выигрыш растёт с кодом. Окно дешёвой миграции — пока бэкенд мал; целевое — сразу после перевода отделов (январь).

**Открытые вопросы:** нет; ждём поддержку typescript-eslint.

**Связи:** #75, `docs/architecture/tech-stack.md`.

**Статус:** зреет — триггер: typescript-eslint поддержит TS 7 (проверить при переводе отделов, январь).
