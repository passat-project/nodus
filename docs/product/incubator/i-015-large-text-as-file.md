# И-015 · Отправка большого текста файлом

**Дата:** 2026-09-24

**Суть:** при наборе очень длинного сообщения предлагать отправить его файлом (референс — Telegram Desktop 6.7.6). Владелец 24.09: «не нужно сейчас, но идея прикольная».

**Разбор:** за — читаемость ленты: «простыня» (протоколы совещаний, пояснения ТЗ — частый жанр стройки) превращается в карточку вложения, в сообщении остаётся короткая суть; дёшево ложится на механику вложений A1. Против — текст внутри файла выпадает из поиска по ленте до появления полнотекстового поиска по вложениям. Поэтому только ПРЕДЛОЖЕНИЕ по порогу (например, > 2000 символов), не автоконвертация, иначе смыслы начнут прятать в файлы.

**Открытые вопросы:** формат файла (txt/md/pdf)? Оставлять ли первые строки-выжимку в сообщении? Порог?

**Связи:** #41 (A1 — механика вложений), И-002 (поиск по письмам), И-008.

**Статус:** зреет — триггер: появится полнотекстовый поиск по вложениям или запрос тестировщиков.
