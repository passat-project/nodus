# И-039 · Реестры записей и кнопки без смены статуса

**Дата:** 2026-11-03

**Суть:** Шайдерова — все задания смежникам одного раздела в одной задаче, но с единым реестром выдач по датам и отметками «выдано / принято»; выдач 10–20 за жизнь комплекта, статус на каждую не меняется. Владелец обобщил: нужна логика хранения записей — реестры с любыми колонками (выдачи заданий; книга номеров изменений «15-26» на всю компанию; позже накладные, замечания).

**Разбор:** согласовано 03.11 — реестр: таблица со своими колонками-атрибутами и переключателями («выдача с подтверждением», «нумерация с годом», «только добавление»); настраивается и целиком смотрится (по правам) в «Автоматизации → Реестры». Строки пишут только кнопки маршрутов; новый элемент маршрута «Действие» — кнопка без смены статуса (окно + что сделать), учёт времени в статусах не портит. Тип задачи и тип проекта закрепляют вкладки реестров, «+» — личные; рамку задаёт место, чужие проекты из карточки не видны. Получатель — комплект смежника + человек; «принято» = получил и ознакомился; перевыдача после Изм. — тем, кого касается. Будущие файлы в Nodus — колонкой «документ» рядом с путём, без переделок.

**Открытые вопросы:** сколько задач на выдачу (одна на раздел / на пару «кто → кому» с передачей хода / две) и где отработка — интервью руководства (`docs/mvp/interview-plan-assignments-2026-11.md`); атрибуты — один атрибут на несколько сущностей, привязка галочками вместо вкладок-областей.

**Связи:** #557, #38, #435, #434, #436, #469; ADR-0024, ADR-0029, ADR-0030; И-004, И-037.

**Статус:** обсуждается — ждём интервью Шайдеровой и решения по атрибутам.
