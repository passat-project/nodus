# И-034 · Вкладки карточки проекта: DnD и первичная

**Дата:** 2026-10-29

**Суть:** вкладки рабочей зоны карточки проекта («Задачи / Канал / Участники / История» + личный набор через «+») должны переставляться drag-and-drop, а пользователь — задавать, какая вкладка открывается по умолчанию. Слова владельца 29.10: «чтобы каждый мог под себя настроить, как ему удобно».

**Разбор:** механика ложится на уже принятый канон персонального порядка (`ui-prefs-store`, DnD модулей рейки) — тот же стор и паттерн drag за заголовок, что у колонок таблиц. Нужно: реестр вкладок с id/иконкой/содержимым и «закреплённой» первичной; память порядка и первичной per user (не per project — иначе карточки ведут себя по-разному); миграция `nodus-project-tabs-v1` в общий стор; решение, можно ли скрывать «Задачи» (сейчас нельзя — рабочая зона не должна пустеть); та же механика понадобится вкладкам письма (#542) и сотрудника — делать ОДНИМ движком.

**Открытые вопросы:** можно ли скрывать «Задачи»? Первичная — per user или per project (рекомендация — per user)? Системный дефолт #467 («Структура», если есть узел с задачами) перекрывается личным порядком?

**Связи:** #52, #467, #542, `nodus-ui-style` (персональный порядок), `ui-prefs-store`.
