# Фон зоны чата (#849) — рабочий концепт

Статус: **draft-issue #849**, живой концепт на песочнице `:4173`; в `main` не входит.
Фон — осознанное исключение из канона «Инструмент» (градиент + декор только в зоне
чата), нужен ADR и вердикт владельца.

## Что на экране

- **Слой:** мягкий градиент + плотная хаотичная россыпь **отдельных** иконок;
  ни соединительных линий, ни сетки. Слой статичен относительно панели чата и не
  скроллится с лентой (модель обоев Telegram).
- **Иконки:** 114 форм — Lucide 1.66 (ISC) + 6 собственных доменных (кран,
  экскаватор, конвейер, труба, жилет, уровень) + знак Nodus с окна входа
  (центральный гексагон + три балки + три точки, без рамки).
- **Раскладка:** blue-noise — точки расслабляются с учётом радиусов, размер каждой
  иконки выводится из свободного места. Плитка 960 px: 307 значков, минимальный
  зазор 3,4 px, максимальная пустота 7,7 px (самопроверка генератора).
  Одинаковая иконка не встречается ближе 110 px; угол поворота ±18°.
- **Бесшовность:** всё, что пересекает край плитки, дублируется на противоположной
  стороне — на широком экране нет вертикальной пустой полосы.
- **Композер:** обои на всей колонке чата, полоса композера прозрачная; остров ввода
  остаётся непрозрачным — фон не обрывается вокруг него.
- **Темы:** светлая — тёплая бумага (`#f2ede6 → #e1dad1`) + индиго 8%, сила иконок
  8%; тёмная — база `#0A0A0B` + закатные пятна (фиолетовый/розовый/оранжевый) +
  нижний scrim, сила 6%.
- **Поверхности:** все ленты чата (беседа, тред, канал, заметки, обсуждение задачи);
  список бесед и панели — без узора.

```bash
cd docs/design/messenger-wallpaper

```

репозитория — их история в issue #849.

## Механика в продукте

- Класс `.chat-wallpaper` в `packages/ui/src/styles/globals.css`: несколько фонов
  (SVG-плитка + радиальные/линейные градиенты), `background-size: 960px 960px, cover`,
  `background-repeat: repeat, no-repeat`. Цвет и сила иконок запечены в SVG — фоновое
  изображение не умеет `currentColor`; поэтому две плитки под темы.
- Класс ставится на **корень панели чата** (не на скроллер): `background` элемента с
  прокруткой не скроллится с содержимым, а полоса композера остаётся в том же слое.
- Композер (`chat-composer.tsx`) без заливки полосы — остров `bg-card` лежит поверх обоев.
