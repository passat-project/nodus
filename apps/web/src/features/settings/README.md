# features/settings — «Настройки портала»

Вход — меню «Настройки» левой рейки (`app/shell/node-rail.tsx`), маршрут
`/settings`, доступ — право `portal.settings.manage`. Разделы — вкладки
ТОПБАРА из реестра навигации (`app/shell/nav-registry.ts`, запись `settings`
с `rail: false`: в рейке, персональном порядке и «Скрытом» страницы нет) —
вердикт владельца 16.11.2026: левое перечисление разделов не наш стиль и
отнимало ширину у матрицы прав. Каркас минимальный: #276 добавит остальные
разделы, #871 — «Компанию».

## Что есть

- **`pages/portal-settings-page.tsx`** — страница: `?tab=access` — «Права
  доступа», `?tab=ai` — «ИИ-агент», иначе «Файловые серверы». Без права —
  «Нет доступа», вкладки топбара скрыты тем же правом.
- **ИИ-агент (#894, #902)**: `components/ai-settings-section.tsx` —
  контейнер разделов **Провайдеры / Навыки / MCP** (выбор в тулбаре между
  «Создать» и поиском, `?section=`), `ai-providers-section.tsx` — реестр
  провайдеров моделей с окном правки, `ai-mcp-section.tsx` — реестр внешних
  MCP-серверов (адрес, ключ, «по умолчанию для поиска», проверка
  соединения), `ai-skills-section.tsx` — честное пустое состояние до Ф4.
  Под реестром провайдеров — полоса **«Модели по умолчанию»**
  (`components/ai-default-models-bar.tsx`, #917): основная модель прогона и
  пара «провайдер + модель» диспетчера инструментов; сохранение — `PUT
/settings/ai`, модель обязана принадлежать выбранному провайдеру.
  Общий каркас — `ai-registry-header.tsx` (шапка h-14, тулбар, шестерёнка
  полей), данные — `api/ai-settings.ts` и `api/mcp-settings.ts`.
- **`components/file-servers-section.tsx`** — список `\\server\share`
  (#558): добавление и удаление сохраняются сразу (оптимистично, откат при
  ошибке); пустой список — ничего не открывается.
- **`components/file-servers-sync.tsx`** — один запрос списка на сессию
  оболочки: кладёт снимок в `shared/desktop/file-servers-store.ts`, который
  читает значение-путь. В браузере не грузится (там путь копируется).
- **`api/file-servers.ts`** — `GET/PUT /api/v1/settings/file-servers`,
  ключ кэша `['settings','file-servers']`.
- **`api/mocks/file-servers-handlers.ts`** — MSW-домен `settings`: запись
  только с правом, стартовый список пустой.

## Правила

- Чтение списка — всем аутентифицированным (веб решает, показывать ли
  действия у пути); запись — только `portal.settings.manage` (сервер
  проверяет сам, I8).
- Строки UI — из `ui.portalSettings` (`ru-settings.ts`), формат и грамматика
  `\\server\share` — `packages/contracts/src/settings/file-servers.schema.ts`
  (общая для веба, моков и сервера).
- Путь открывает только десктоп-оболочка: команды моста `open_unc_path` /
  `reveal_unc_path` (`shared/desktop/desktop-bridge.ts`); в браузере —
  «Скопировать путь».
