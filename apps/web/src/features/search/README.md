# Фича search (веб)

Единое окно поиска по порталу (#952): Ctrl+K — диалог с панелью фильтров
слева и плотной выдачей справа. API — `GET /api/v1/search` (ядро `search`),
контракт — `packages/contracts/src/search/search.schemas.ts`.

## Одно состояние (поверхность A, решение владельца 18.11.2026)

Рабочего листа нет: всё живёт в окне `SearchCommand`
(Ctrl+K или лупа в шапке; Esc / клик по фону закрывают). Ширина 880px,
высота до 540px.

- **Слева** — `SearchFilterRail` (176px): типы с количествами-фасетами
  (видны все пять источников; нулевые приглушены), период, сортировка,
  проект (при включённом модуле), сброс фильтров. Общий счётчик найденного —
  у строки «Все типы», не в шапке.
- **Справа** — поле запроса на всю ширину выдачи, единый ранжированный
  список (без группировки: плотнее и не дублирует панель типов),
  «Показать ещё» — строкой в конце списка. При пустом поле — недавние
  запросы, а если их нет — подсказка.
- **Каретка** — «вечный курсор» как в чатах (`shared/chat/composer-focus`):
  клики по фильтрам, кнопкам и пустому месту возвращают фокус в строку
  поиска; открытый список проекта владеет фокусом, после закрытия каретка
  возвращается. Крестик в поле: пустое — закрыть окно, с текстом — очистить.
  Esc и клик мимо окна закрывают.
- **Строка выдачи** — два слоя текста: заголовок (у сообщения — подпись
  беседы) с датой справа и одна вторичная строка — сниппет найденного
  фрагмента, а если совпадение в названии — номер/проект/корреспондент.
  Чипы типов и причин совпадения не показываются.

Состояние — общий Zustand-стор `model/search-store.ts` (`open`, `query`,
`types`, `projectId`, `period`, `sort`): закрытие окна не теряет запрос.

## Модель

- `api/search-api.ts` — `useSearchResults` (`useInfiniteQuery` по курсору,
  `keepPreviousData` — выдача не мелькает при вводе), `searchRequestOf`
  (period → `from`), `searchPath` (`types=task,letter`).
- `api/mocks/search-mock.ts` — мок-мир P1: пять источников из демо-данных,
  фильтры/фасеты/курсор/подсказки/маркеры — по правилам сервера; видимость
  писем и проектов — функциями модулей. `search-handlers.ts` разбирает
  параметры ТОЙ ЖЕ zod-схемой, что API (400 на `q<2`).
- `components/snippet-text.tsx` — сниппет с маркерами `\u0001`/`\u0002`:
  только текстовые узлы, никакого HTML.
- `lib/open-result.ts` — карточка в стек (мост `openCardViaBridge`); для
  сообщения — мессенджер + существующий `jump-store` (скролл, вспышка 2 с,
  бэкфилл), при `threadRootId` — сначала `stageMessengerThread`.
- `model/search-recent.ts` — недавние запросы в localStorage на пользователя
  (`nodus-search-recent-v1:<userId>`, максимум 8).
