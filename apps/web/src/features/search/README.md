# Фича search (веб)

Единое окно поиска по порталу (#952): компактное Ctrl+K и рабочее внутри
рамы. API — `GET /api/v1/search` (ядро `search`), контракт —
`packages/contracts/src/search/search.schemas.ts`.

## Два состояния одного окна (поверхность A, решение владельца Д2)

| Состояние               | Вход                         | Выход                                  | Что внутри                                                                                                                                       |
| ----------------------- | ---------------------------- | -------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| Компакт `SearchCommand` | Ctrl+K, лупа в шапке         | Esc, клик по фону, открытие результата | Radix Dialog 640px, до 60vh: поле, группы по типам 4 строки, недавние, «Открыть поиск»                                                           |
| Рабочее `SearchPanel`   | «Открыть поиск» / Ctrl+Enter | Esc, Ctrl+K, крестик                   | Лист во всю ширину рамы ниже шапки (top — `useCircuitAxisY`, z-62): фильтры сверху, фасеты слева (240px), список, превью (320px), «Показать ещё» |

Пункта «Поиск» в левой рейке **нет** (ответ владельца). Ширины: <1100px —
превью скрыто, <760px — фасеты скрыты. Состояние — общий Zustand-стор
`model/search-store.ts` (mode, query, types, projectId, period, sort): Ctrl+K
из рабочего окна закрывает его, запрос сохраняется.

## Модель

- `api/search-api.ts` — `useSearchResults` (`useInfiniteQuery` по курсору,
  `keepPreviousData` — выдача не мелькает при вводе), `searchRequestOf`
  (period → `from`), `searchPath` (`types=task,letter`).
- `api/mocks/search-mock.ts` — мок-мир P1: пять источников из демо-данных,
  фильтры/фасеты/курсор/подсказки/маркеры — по правилам сервера; видимость
  писем и проектов — функциями модулей. `search-handlers.ts` разбирает
  параметры ТОЙ ЖЕ zod-схемой, что API (400 на `q<2`).
- `components/snippet-text.tsx` — сниппет с маркерами `\u0001`/`\u0002`:
  только текстовые узлы, никакого HTML.
- `lib/open-result.ts` — карточка в стек (мост `openCardViaBridge`); для
  сообщения — мессенджер + существующий `jump-store` (скролл, вспышка 2 с,
  бэкфилл), при `threadRootId` — сначала `stageMessengerThread`.
- `model/search-recent.ts` — недавние запросы в localStorage на пользователя
  (`nodus-search-recent-v1:<userId>`, максимум 8).
