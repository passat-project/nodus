# features/directory

Сотрудники в теме «Инструмент» (#768, вердикт владельца 12.11.2026): две
вкладки — **«Список»** (дефолт, каноническая таблица) и **«Структура»**
(управленческое дерево подразделений + правая панель). Старые адреса
нормализуются заменой URL: `?view=divisions` и `?view=subordination` →
`?view=structure`; `?view=settings` и неизвестный `view` → «Список»
(остальные параметры, включая `cards`, сохраняются — `lib/employees-tab.ts`).
Шапка — ОДНА строка h-14 без border-b: заголовок со счётчиком штата голым
числом (действующие сотрудники; уволенные остаются в журнале, но в счёт не
входят — то же определение, что у карточки «Сотрудники» на Главной, #723),
**primary «Пригласить» слева только администратору** (`directory.manage`; у
остальных сразу поиск/таблица), поиск по структуре шириной как в «Списке»
(28rem, сжимается до `min-w-56`; на узких ширинах уходит в иконку) и справа
«Список должностей» — иконка `IdCard` 20px (≈25 экранных) с нативной подсказкой (вердикты
16–17.11.2026: текстовая кнопка перекашивала шапку, портфель читался как
«проекты», 16px-иконка была мельче соседних действий). Шапка всегда
резервирует ширину постоянной правой панели, поэтому инструменты не двигаются
и не прячутся.
В «Списке» — строка инструментов. Диалог приглашения — по-прежнему заготовка
(`components/invite-dialog.tsx` → `POST /directory/invitations`, полный поток —
с бэкендом директории).

- **Структура** (`components/divisions-view.tsx`) — дерево карточек
  управленческих подразделений в грамматике контура Nodus. **Карточка**
  (`components/structure-node.tsx`) — фиксированная высота `STRUCTURE_CARD_HEIGHT`
  (10.25rem): шапка (название `text-base font-semibold` с обрезкой, бейдж
  главной; «⋯» правки подразделения администратору — sibling кнопки-тела, чтобы клик
  по меню не выбирал подразделение), руководитель (аватар, имя, должность под именем) с
  чипом команды, два столбца вплотную к руководителю («Подчинённые» — число с
  формой слова, «Заместители» — 0 пусто / 1 имя / N число) и футер с числом
  подразделений и шевроном. Бейдж «Ваше подразделение» — на верхнем правом краю (вне потока
  шапки, `pointer-events-none`, нейтральный тон `bg-foreground`); его видит
  КАЖДЫЙ: у кого нет активного подразделения (или подразделение архивное), бейдж стоит на
  главной карточке компании — там же, где такой сотрудник показан (вердикт
  17.11.2026). Данные — `lib/department-card-stats.ts`: один расчёт на
  страницу из уже загруженного справочника; чип листа — подчинённые + замы,
  ветки — плюс все сотрудники подразделений с их руководителями; в главной
  карточке «беспризорные» (без подразделения/с архивным) — в «Подчинённых».
  Видны только активные сотрудники. **Раскладка — фиксированные слоты**
  (вердикт 16.11.2026): слот узла — только карточка w-60, ряд детей —
  абсолютный слой, отцентрованный под родителем; раскрытие не меняет x
  карточек других уровней, дети могут заходить под соседей уровнем выше. Шаг
  уровней = 2H, высота соединения узла с детьми = H (одна константа на
  высоту карточки и отступ детей). Рёбра — ортогональные 1px на `--edge` с
  портами r=3 и скруглёнными локтями единого радиуса `uiPx(8)` (как контур
  модулей); стык ствола с шиной — не тройник: шина с обеих сторон заворачивает
  вверх двумя дугами и сливается с вертикалью НАД шиной (ствол проходит вершину
  насквозь), при нечётном числе детей
  вертикаль продолжается в центральную карточку (`lib/tree-edge-geometry.ts`,
  снап к сетке устройства с учётом зума (`snapBoard`); отвод входит в шину
  касательно — каждый сегмент ровно один штрих,
  gotchas SVG-графа; шина укорочена до начал дуг — хвостов за поворотом нет;
  панорама полотна округляется до пикселя устройства — линии не «плавают» на
  дробных зумах; обмер живого DOM — `lib/use-tree-edges.ts`; маршрут импульса —
  та же линия). **Раскрытие — аккордеон по уровням, как в Битриксе**: главная
  карточка и её прямые подразделения видны по умолчанию; на каждом следующем
  уровне раскрыт один узел — цепочка к выбранному (`lib/department-tree.ts`,
  `keepChain`). Клик по соседу на уровне закрывает прежнюю ветку, клик по уже
  раскрытому предку глубокие уровни НЕ закрывает, клик по выбранной раскрытой —
  no-op. **Шеврон футера** сворачивает ветку целиком (дети и все уровни глубже),
  повторное раскрытие — один уровень; если внутри стояло выбранное подразделение, выбор
  и панель переходят на карточку шеврона; у карточки без подразделений шеврона нет
  (подпись «Нет подразделений в подчинении»). Клик по телу выбранной свёрнутой
  карточки раскрывает её. Под ВЫБРАННОЙ карточкой администратору — «плюс»
  создания подразделения: на линии при видимых детях, вплотную к низу у
  последней в маршруте. **Маршрут к выбранному** подсвечен: предки — контуром
  1px в тоне линии со свечением (`--glow`), выбранная — контуром 2px с мягким
  кольцом (габарит не меняется, соседи не двигаются). По маршруту бежит
  точка-импульс со следом
  (`components/structure-trace.tsx`: скорость `edgeDurations().draw` — 1200 px/s,
  точка и закрашиваемая линия ведутся одним прогрессом; `lib/trace-plan.ts` —
  общий префикс прошлого маршрута не перепроходится, точка стартует от карточки
  расхождения; выбран предок — точки нет, закрашенный след остаётся;
  `prefers-reduced-motion` — закрашивание сразу). SMIL здесь не используется:
  динамически вставленный `animateMotion` стартует от времени документа и
  замирает — ловушка в gotchas frontend.
  **Главная карточка компании** — первый корень: иконка и бейдж, тонированный
  фон, полужирное название; если корней нет — главной карточки нет (пустое
  состояние с созданием для админа). **Центрирование — только по явному
  запросу**: при входе на вкладку моё подразделение (или ранее выбранное)
  центрируется и его панель открыта; если моего нет/оно архивно/нет членства —
  центрируется главная карточка (первый корень), панель показывает её. Выбор из
  поиска центрирует; раскрытие, шеврон, клик по карточке и сброс масштаба
  полотно НЕ двигают (сброс — на месте: 100% вокруг центра свободной части
  вьюпорта без панели, выбранное подразделение не меняется, вердикт 17.11.2026). Центр
  учитывает ширину постоянной правой панели
  (`PANEL_INSET_PX`; место зарезервировано всегда), панорама — сдвиг полотна.
  Дерево НЕ фильтруется поиском: поиск живёт в шапке, раскрывает путь и
  центрирует. Контейнер дерева по ширине вьюпорта (не по самой широкой строке) —
  рост ветки не перецентрирует всё дерево. **Полотно как в редакторе**:
  Ctrl/⌘+колесо — зум к курсору 30–200% (пинч тачпада = ctrl+wheel), колесо без
  Ctrl — панорама, зажатая ЛКМ по пустому месту — перетаскивание
  (`lib/canvas-view.ts`, `lib/use-canvas-view.ts`; жест по полотну — клик, драг,
  колесо — снимает фокус с полей шапки: поиск структуры не висит «активным» после
  работы с канвасом, вердикт 17.11.2026; pointerdown из порталов
  Radix — меню «⋯», диалоги, поповеры — панораму НЕ начинает, хотя React
  всплывает его по дереву компонентов; рёбра `lib/use-tree-edges.ts`
  пересчитываются с учётом масштаба, сравнение — с идентичностью узла, иначе
  после оптимистичной вставки в маршрутах остаётся `temp-…` и след исчезает;
  текст карточек при панораме не выделяется). Фон — точечная сетка как в
  автоматизации (`components/structure-dots.tsx`: слой во вьюпорте под
  контентом, gap/радиус от `uiPx(28)`/`uiPx(1)`, едет и масштабируется с
  полотном). В углу — «Найти меня» (`LocateFixed`: выбор себя через поиск —
  моё подразделение, панель, подсветка и скролл моей строки, центрирование,
  импульс) и индикатор масштаба (клик — сброс на 100% на месте). Меню «⋯»
  раскрывается ВПРАВО от карточки (`side="right"`), не накрывая её.
- **Поиск по структуре** (`components/structure-search.tsx`) — подразделения и
  активные сотрудники в одной выпадашке (ФИО/должность); выпадашка открывается
  ТОЛЬКО при введённом тексте (пустое поле не показывает мелькающее окно); выбор
  подразделения раскрывает путь и открывает его панель, выбор сотрудника
  центрирует его подразделение, открывает панель и подсвечивает строку
  (сотрудник без управленческого подразделения/с архивным ведёт в главную
  карточку). Запрос очищается после выбора; «ничего не найдено» — в выпадашке.
  На узкой шапке поиск уходит в иконку с той же выпадашкой (`compact`).

  карточке или пустому месту канваса — клик только выбирает подразделение,

  карточке компании в «Подчинённых» дополнительно видны активные сотрудники

  Действия
  подразделения (меню, только администратору): пригласить, править — «Добавить
  подразделение» из меню убрано (вердикт 17.11.2026): создание — только «плюсом» на
  карточке. Диалог — `components/department-dialog.tsx` (название +
  руководитель + зам автокомплитом `components/employee-combobox.tsx`; при

  ошибке); архивация — кроме главной карточки компании, после успеха панель
